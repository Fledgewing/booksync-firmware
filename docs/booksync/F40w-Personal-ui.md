# F40w Discover and Recommended widgets

The approved X4 Pro and Classic cards use the F34 immutable Library batch.
Discover requests four F39-ranked books in one 2 by 2 card. Its independent
fifty-pixel Another and All targets preserve the current source scope. The
1 by 1 Recommended card shows one prepared pick and its reading-history caption.
X3 installs neither kind. No reader interaction or sync writer changes.

Each card has one pure renderer. Prepared cover pixels and builtin glyphs are
painted without acquisition, filesystem access, allocation or Library calls.
Every source state remains independent, including known zero, missing, off,
unsupported, failure, oversize and stale; a failed Discover leaves its siblings
usable. Saved age is displayed only when proven.

The existing capture owner registers borrowed immutable values through
`bindHomePersonalSources`. A private normalized full-ranking source backs
Discover All; absent membership remains unavailable rather than substituting
another preset or the on-card index. Another is an explicit callback through
the Library interface. Account retirement clears previews and full membership.
No new task, network path, backend rule or writer is introduced.

Verification: provider tests cover F39 ranking and budgets; renderer/host tests
cover all states, actions and geometry, with independent integration tests for
scope retirement, duplicate rows and sibling isolation. Native scenes exercise
both X4 profiles and prove X3 exclusion. The review gallery pairs actual native
captures with the approved source PNG crops at each approved size.

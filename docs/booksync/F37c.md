## Android reference and retention

BookSync integration commit `ed740a0b`:
`android/koreader/orbit.koplugin/logic/account.lua:19–33` supplies the conditional
sign-out wording; `:43–56` supplies origin-result wording. Its account UI at
`ko/account.lua:93–143` provides independent login/removal/replace controls.
Companion `AccountActivity.kt:33–69` confirms three optional logins and the
explicit derived-sync-key input mode. The approval PR maps every proposed state
to these source branches; it contains no private photograph or credentials.

Server account, sync and OPDS credentials are independent. Signing out removes
the account session and account-supplied connectors; separately entered connectors
stay. Local downloaded books and native places stay. Stats from other devices
stop. Removing one connector affects that connector only. UI must consume these
origins from Library, not infer them from names/addresses. Account sign-in fills
empty slots without overwriting user-owned connectors; replacement is explicit.

`services/Account.cpp:105–117` already implements origin-sensitive sign-out;
`:134–163` owns independent removal/replacement with epoch checks. This slice
adds policy regression coverage without exposing those operations through an
unapproved screen. No service or adapter behavior changes are claimed.
